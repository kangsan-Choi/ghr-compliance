## Key Statutes and Articles

- 労働基準法 第32条: 법정 근로시간 (1일 8시간, 주 40시간)
- 労働基準法 第36条: 36협정, 시간외 일반 한도 월 45시간/연 360시간, 특별조항 절대 상한 월 100시간 미만/연 720시간
- 労働基準法 第37条: 할증임금율 (25%/35%/50%)
- 労働基準法 第39条: 연차유급휴가, 연 5일 취득 의무 (2019.04~), 30만엔 벌금
- 労働基準法 第20条: 해고 30일 예고 또는 예고수당
- 労働契約法 第16条: 해고권 남용 법리
- 労働契約法 第18条: 유기계약 5년 무기전환 룰
- 育児介護休業法: 산전6주+산후8주, 육아휴업, 파파육휴(4주, 2022.10~)
- 最低賃金法: 도쿄도 최저임금

## Key 2024-2026 Legislative Changes
1. 2023.04: 중소기업 월 60시간 초과 할증율 50% 적용 (유예 폐지)
2. 2024.04: 건설·운송·의사 시간외 상한 규제 적용 (유예 업종 해제)
3. 2024.04: 노동조건 명시 규칙 개정 (변경 범위, 갱신 상한, 무기전환 명시 의무화)
4. 2025.04: 육개법 개정 1차 (간호휴가 확대, 3세~취학 전 유연근무 2가지 이상 의무)
5. 2025.10: 도쿄 최저임금 1,226엔
6. 2026~: 노동기준법 대폭 개정 심의중 (제출 일단 유예, 44시간 특례 폐지 등 예상)
